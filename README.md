# 🕒 WorkPulse

A full-stack Attendance Management System built using the MERN stack that allows employees to **check in, check out, and track working hours in real-time**. It uses OOPS principles for clean, structured, and reusable backend code with secure authentication and live status updates.

---

## 🚀 Features

- 👤 User Authentication (Login/Register)
- 🟢 Check-In / 🔴 Check-Out system
- ⏱️ Automatic working status tracking
- 📊 Attendance history per user
- 🔐 Secure backend with API validation
- 📱 Responsive UI for mobile & desktop
- ⚡ Real-time status update (Working / Not Working)

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Axios
- Tailwind CSS / CSS

**Backend:**
- Node.js
- Express.js
- MySQL
- JWT Authentication

## ⚙️ How It Works

1. User logs in
2. Clicks **Check In → status becomes 🟢 Working**
3. Clicks **Check Out → status becomes 🔴 Not Working**
4. System stores timestamps in database
5. Admin can view attendance records

## 📦 Installation

```bash
# Clone repository
git clone https://github.com/Ankana-Sadhukhan/WorkPulse.git

# Backend setup
cd server
node app.js
```
# Frontend setup
cd client
npm install
npm start
